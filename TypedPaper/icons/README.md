# Classic desktop icons

Selected 32px icons from Tango Icon Theme 0.8.90.

Source: https://tango.freedesktop.org/releases/tango-icon-theme-0.8.90.tar.gz

The upstream COPYING file releases these icons into the Public Domain; the original notice is preserved in COPYING. These images provide a classic desktop appearance inspired by early desktop software. No Apple system icon files are included.

All icons are bundled locally; no external icon requests are needed at runtime.
